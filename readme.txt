AI chatbot that answers visitors' questions from your own content (posts, pages, products, events) and cites the sources.

== Description ==

Scairato AI Content Chat adds a search-style chatbot to your site. It indexes your published content, finds the passages that match each question (semantic search) and asks an AI model to write an answer based **only** on them, with links to the sources.

**Features**

* Semantic search (embeddings) + answer generated by an LLM (OpenAI or any OpenAI-compatible API).
* Indexes posts, pages, WooCommerce products, events and any public custom post type; works with Gutenberg, Elementor, Avada and other builders (it indexes the rendered content).
* Source citations with links. When the site has no answer, no sources are shown.
* Floating launcher, Gutenberg block and the `[saic_chat]` shortcode.
* 3 ready templates (classic, modern, minimal). Override the HTML/CSS from your theme: `your-theme/scairato-ai-content-chat/<template>/`.
* **Extra sources**: teach the chat information that is not in your posts (address and opening hours in the footer, ACF options, fixed text) by reading a page of your site with a CSS selector.
* Complete lists and counts: questions such as "list all products for pastures" use your categories and return every item.
* Automatic (WP-Cron) or manual reindexing (admin screen or WP-CLI).
* Question history in the admin, with CSV export and configurable retention.
* Usage limits per visitor and per day to control costs.
* WP-CLI: `wp saic status | index | sources | index-post | delete | clear | search | ask | history`
* Translation-ready (translate.wordpress.org). The chat answers in the visitor's language.
* Supports reasoning models: leave "Temperature" empty; optional "Reasoning effort" and "Max output tokens".

You need your own API key from an OpenAI-compatible provider. The plugin does not include or resell any AI service.

== External services ==

This plugin connects to an AI provider that you configure. By default it is **OpenAI** (`https://api.openai.com/v1`). You can point it to another OpenAI-compatible endpoint in the settings.

**What is sent and when**

* *When indexing* (after you publish or edit content, on a manual reindex, or via WP-CLI): the public text of your published content (title, text, excerpt, categories and the custom fields you list in the settings) and the text of the "Extra sources" you configure, to create embeddings (`/embeddings`).
* *On each visitor question*: the question, the most relevant passages from your content, the last few messages of the conversation (if enabled) and the current date, to generate the answer (`/chat/completions`) and to create an embedding of the question (`/embeddings`).
* Your API key is sent to the provider for authentication. It is stored in your database (or defined in `wp-config.php` with `SAIC_OPENAI_API_KEY`) and is never shown again in the admin.

No data is sent until you enter an API key.

**Provider terms (OpenAI)**

* Terms of use: https://openai.com/policies/terms-of-use
* Privacy policy: https://openai.com/policies/privacy-policy

If you use another provider, check its terms and privacy policy. You are responsible for informing your visitors that their questions are processed by an AI provider (a suggested text is added to the WordPress privacy policy guide).

The "Extra sources" feature may also request pages of your **own** site (as a logged-out visitor) to read their text; it never requests other domains.

== Installation ==

1. Upload the plugin to `/wp-content/plugins/scairato-ai-content-chat/` or install it from the Plugins screen, then activate it.
2. Go to **Scairato AI Content Chat > Settings**, enter your API key and choose the content types to index.
3. Go to **Scairato AI Content Chat > Index** and click "Reindex changed items".
4. Show the chat: enable the floating button in the settings, add the "Scairato AI Content Chat" block, or use the shortcode `[saic_chat]`.

== Frequently Asked Questions ==

= Do I need an API key? =
Yes. Create one with your AI provider (OpenAI by default) and paste it in the settings. Usage is billed by the provider.

= Which models work? =
Any embeddings model and chat model offered by an OpenAI-compatible API. Reasoning models are supported: leave "Temperature" empty.

= The chat cannot find my address, opening hours or other information from my theme. =
Use **Scairato AI Content Chat > Extra sources**: add a fixed text, or read a part of a page with a CSS selector (for example `footer .contact`) and click "Reindex sources now".

= The chat does not know the dates of my events. =
Add the custom field names (for example `_EventStartDate`) in **Settings > Extra custom fields** and reindex.

= Where is the index stored? =
In two tables of your own database (`{prefix}saic_chunks` and `{prefix}saic_log`). Nothing is stored outside your site except what the AI provider receives (see "External services").

= How do I remove everything? =
Check "Delete index, history and settings when the plugin is deleted" in the settings, then delete the plugin.

= Does it use the WordPress AI Client? =
Not yet. The plugin needs embeddings to search your content, and the AI Client in WordPress 7.0 and 7.1 does not provide an embeddings API, so it connects directly to the OpenAI-compatible endpoint you configure. See the External services section.

= Can I customize the look? =
Yes: pick one of the three templates, set the primary colour, copy a template folder to `your-theme/scairato-ai-content-chat/<template>/` to change its HTML/CSS, or use the available filters (`saic_system_prompt`, `saic_template_data`, `saic_response`, `saic_search_hits`, `saic_is_indexable`).

== Privacy ==

Visitors' questions are sent to the configured AI provider. If the history is enabled, questions and answers are stored in your database with an anonymous identifier (IP hash) and, for logged-in users, their user ID, for the retention period you choose. A suggested text is added to the privacy policy guide (**Settings > Privacy**).
